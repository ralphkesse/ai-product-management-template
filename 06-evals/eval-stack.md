## What "good" means

≥75% of insights left unoverridden; reprocess rate ≤15%

Active: accept/override on each insight card (promote, demote, clear not-recommended), Reprocess Transcript clicks, override reason text
Passive: time-to-first-override, insights left untouched (silently accepted), PRD copied/exported, PRD edited before use, session abandoned before reviewing all insights

## Golden set

150 anonymized transcripts (interview/ticket/email mix), PM-curated expected priority + notRecommended label per insight
Split evenly across Strategy Mode and Quality Mode
Versioned in 06-evals/golden-set/
Refresh quarterly (and after any bad prioritization ships)

## Release gate

**Hard gates (auto-block):**

0% fabricated citations — any quote that doesn't exist verbatim in the source transcript blocks the release
0 critical failures (score of 1) on Evidence Grounding or Calibrated Uncertainty at the human-eval layer
Golden-set anti-pattern detection accuracy <90% → block

**Soft gates (PM sign-off):**

P99 latency >8s requires PM justification
Override rate >20% on the same insight type in a week requires PM review before the next release
Golden-set priority accuracy between 80–90% (below pass bar, not catastrophic) requires PM sign-off to ship

**User-feedback layer (online):** cadence Per request (real-time) + weekly aggregate review; owner PM owns the weekly review; PM lead triages if ≥2 overrides land on the same insight type within 24h.
